# Osobnyak Lead Hunter

Система поиска релевантных публичных запросов в Threads для «Особняк Event» (Ростов-на-Дону), с подготовкой персонализированных ответов и подтверждением человеком перед публикацией.

## Текущий статус
Приложение Meta создано, но Threads OAuth, разрешения и токены ещё не подключены. Реальные поиск и публикация недоступны.

## MVP
1. PostgreSQL: публикации, авторы, лиды, история взаимодействий и запреты контакта.
2. ThreadsProvider: mock для локальной разработки, официальный Threads API после подключения.
3. Фильтрация по явной потребности, географии, актуальности, исключение дублей.
4. ИИ-анализ с объяснением решения и генерацией индивидуального комментария.
5. Telegram: карточка лида, одобрить / отклонить / отложить.
6. Очередь публикации, аудит, проверка результатов, метрики.

## Правила
- Использовать официальный API, не обходить ограничения платформы.
- Не публиковать массовые рекламные комментарии автоматически.
- Помолвка без запроса рекомендаций не означает согласия на рекламу.
- Разделять предложения площадки и организации мероприятий.
- Не выдумывать географию, цены и доступность дат.
- Не комментировать повторно один и тот же запрос; учитывать отказы.
- Никогда не хранить секреты в Git.
- Пока Meta не подключена, публикация заблокирована.
- Публикация только после явного подтверждения оператора.
- Не повторять публикацию автоматически при неизвестном результате запроса.

## Стек
Python 3.12+, FastAPI, SQLAlchemy, Alembic, PostgreSQL, aiogram, pytest, Docker Compose.

## Порядок разработки
Сначала рабочий mock-MVP с тестами, затем интеграция Meta OAuth и API.
